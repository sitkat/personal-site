# Отчёты по практическим работам

Один каталог на одну ПР:

```
reports/ПР-1.1/otchet.md      отчёт
reports/ПР-1.1/screens/       скриншоты к отчёту
```

Отчёт составляется **сразу после выполнения работы** — см. скилл `pr-report`
(`.claude/skills/pr-report/SKILL.md`), шаблон — `.claude/skills/pr-report/template.md`.

Конвертация в Word при необходимости:

```
pandoc reports/ПР-1.1/otchet.md -o reports/ПР-1.1/otchet.docx
```
