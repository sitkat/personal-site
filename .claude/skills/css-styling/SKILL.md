# Оформление на CSS

Все стили — в одном файле `css/style.css`. Ни `<style>` в разметке, ни атрибута
`style="..."`.

## Обязательный чек-лист ПР 1.2

В `style.css` должны быть **явно продемонстрированы** и помечены комментарием:

- [ ] селектор тега — `p { ... }`
- [ ] селектор класса — `.content { ... }`
- [ ] селектор идентификатора — `#main-menu { ... }`
- [ ] контекстный (потомок) — `.content p { ... }`
- [ ] дочерний — `.nav__list > li { ... }`
- [ ] смежный (соседний) — `h2 + p { ... }`
- [ ] псевдоклассы ссылок — `:link`, `:visited`, `:hover`, `:active` (порядок LVHA)
- [ ] каскадирование — два правила на один элемент с разной специфичностью + комментарий, какое победит
- [ ] удаление подчёркивания ссылок — `text-decoration: none`
- [ ] цветной фон заголовка
- [ ] стиль горизонтальной линии `<hr>`
- [ ] межстрочный интервал — `line-height`
- [ ] стиль маркеров списка и удаление маркеров — `list-style`
- [ ] рамка у изображения — `border`
- [ ] размножение фона — `background-repeat`
- [ ] позиционирование фона — `background-position`
- [ ] фиксированный фон при прокрутке — `background-attachment: fixed`
- [ ] прозрачность изображения — `opacity`
- [ ] элементы CSS3 — `border-radius`, `box-shadow`, `text-shadow`, `linear-gradient`, `transition`, `@keyframes`/`animation`

Комментарии обязательны — по ним потом собирается отчёт:

```css
/* --- Смежный селектор: первый абзац после заголовка --- */
h2 + p {
  font-weight: 600;
}
```

## Порядок разделов в style.css

```
1. Сброс и базовые настройки (* , body, типографика)
2. Переменные :root
3. Шапка
4. Меню (список -> горизонтальное меню)
5. Макет: колонки
6. Контент: текст, ссылки, списки, hr, изображения
7. Таблицы
8. Формы и кнопки
9. Подвал
10. Эффекты CSS3
11. Адаптивность (@media)
```

## Переменные

```css
:root {
  --color-accent: #d9372b;
  --color-bg: #fdfbe8;
  --color-sidebar: #f6c6cf;
  --color-content: #86dd8a;
  --gap: 16px;
}
```

## Макет в две колонки

Основной способ — Grid, он точно повторяет макет из задания:

```css
.layout {
  display: grid;
  grid-template-columns: 180px 1fr 180px;
  gap: var(--gap);
  align-items: stretch;
}
```

Резервный способ (если по заданию нужен именно float или flex) — `display: flex`
с `flex: 1` у `.content`. На узких экранах колонки складываются в одну:

```css
@media (max-width: 720px) {
  .layout { grid-template-columns: 1fr; }
}
```

## Меню из списка

```css
#main-menu .nav__list {
  display: flex;
  margin: 0;
  padding: 0;
  list-style: none;              /* удаление маркеров */
  background: var(--color-accent);
}

.nav__list > li { border-right: 1px solid #fff; }   /* дочерний селектор */

.nav__link {
  display: block;
  padding: 10px 18px;
  color: #fff;
  text-decoration: none;          /* убрали подчёркивание */
  transition: background 0.25s;   /* CSS3 */
}

/* Псевдоклассы ссылок, порядок LVHA */
.nav__link:link    { color: #fff; }
.nav__link:visited { color: #ffe9e9; }
.nav__link:hover   { background: #a8281f; }
.nav__link:active  { background: #7d1c16; }
```

## Фоновое изображение

```css
body {
  background-image: url("../img/bg.png");
  background-repeat: no-repeat;        /* размножение */
  background-position: right top;      /* позиционирование */
  background-attachment: fixed;        /* фиксация при прокрутке */
  background-size: cover;
}
```

Пути в CSS — относительно самого CSS-файла, поэтому `../img/...`.

## Изображения

```css
.content img {
  border: 4px solid var(--color-accent);
  border-radius: 8px;
  opacity: 0.85;
  transition: opacity 0.3s;
}
.content img:hover { opacity: 1; }
```

## Правила

- Специфичность держать низкой: класс лучше, чем `div.block ul li a`.
- `!important` не использовать — если стиль не применяется, разбираться в каскаде.
- Цвета — через переменные `:root`, а не хардкодом по всему файлу.
- Единицы: `rem` для шрифтов и отступов текста, `px` для рамок, `%`/`fr` для сеток.
- Класс — для повторяющегося оформления, `id` — для единственного элемента
  (`#main-menu`); в отчёте это нужно объяснить (контрольный вопрос 6).
- Проверять результат в браузере после каждой заметной правки, не копить изменения.

## Ответы на контрольные вопросы

Контрольные вопросы к ПР 1.2 перечислены в `CLAUDE.md`. Отвечать на них
своими словами и **со ссылкой на конкретные строки своего `style.css`** —
это то, что проверяет преподаватель.
