# Персональный сайт — учебный проект

Статический сайт-визитка, собранный вручную на HTML, CSS и JavaScript
без конструкторов, сборщиков и готовых шаблонов.

**Автор:** Ситникова Екатерина Георгиевна, группа ПИ1у/24б
**Дисциплина:** Веб-программирование

## Страницы

| Страница | Файл | Содержание |
|---|---|---|
| Главная | `index.html` | Приветствие, дисциплины семестра, форма подписки |
| Карта сайта | `sitemap.html` | Структура разделов, перечень страниц, поиск |
| О себе | `about.html` | Навыки, образование, форма отзыва |
| Услуги | `services.html` | Перечень работ, сроки, форма заказа |
| Контакты | `contacts.html` | Способы связи, график, форма обратной связи |

## Структура

```
*.html            страницы сайта
css/style.css     все стили (718 строк, 100 правил)
js/script.js      скрипты (заполняется в ПР 2)
img/              графика в формате SVG
reports/          отчёты по практическим работам
```

## Практические работы

- **ПР 1.1 — Вёрстка сайта.** Пять страниц с единым блочным макетом:
  шапка, меню, две боковые колонки, контент, подвал. На каждой странице —
  заголовок, текст, изображение, ссылка, список, таблица и форма.
  [Отчёт](reports/ПР-1.1/otchet.md)
- **ПР 1.2 — CSS.** Оформление текста, форм и графики; все виды селекторов,
  псевдоклассы, каскадирование, работа с фоном, элементы CSS3, адаптивность.
  Список навигации превращён в горизонтальное меню.
  [Отчёт](reports/ПР-1.2/otchet.md)
- **ПР 2 — JavaScript, jQuery, jQuery UI.** В работе.

## Как посмотреть локально

Достаточно открыть `index.html` в браузере — сборка не требуется.
Либо поднять локальный сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000
