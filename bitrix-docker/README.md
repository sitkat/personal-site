# Локальное окружение для 1С-Битрикс

Битрикс — это PHP-приложение с базой данных MySQL, поэтому на статическом
хостинге (GitHub Pages) он работать не может. Здесь собрано окружение в Docker:
Apache с PHP 8.2 и MySQL 8, настроенные под требования Битрикса.

## Что внутри

```
Dockerfile           образ PHP 8.2 + Apache с нужными расширениями
php.ini              настройки PHP из требований Битрикса
docker-compose.yml   связка веб-сервера и базы данных
www/                 корень сайта (в git не попадает)
logs/                логи Apache (в git не попадают)
```

## Запуск

```
cd bitrix-docker
docker compose up -d
```

Сайт: http://localhost:8080
База данных снаружи: `localhost:33061`

Остановить: `docker compose stop`
Удалить полностью вместе с базой: `docker compose down -v`

## Параметры базы данных для мастера установки

| Поле | Значение |
|---|---|
| Сервер базы данных | `db` |
| Имя базы данных | `bitrix` |
| Пользователь | `bitrix` |
| Пароль | `bitrix` |

Важно: сервер базы — это `db`, а не `localhost`. Внутри сети Docker
контейнеры видят друг друга по именам сервисов, и веб-сервер обращается
к базе именно по имени `db`.

Пароль пользователя `root` — тоже `root`. Это учебное окружение, доступное
только с твоего компьютера, поэтому простые пароли здесь допустимы. На реальном
хостинге так делать нельзя.

## Установка Битрикса

1. `docker compose up -d`
2. Открыть http://localhost:8080/bitrixsetup.php
3. Выбрать редакцию (для учёбы — пробная версия, она полнофункциональна
   и работает 30 дней) и дождаться загрузки дистрибутива
4. Скрипт распакует архив и передаст управление мастеру установки
5. В мастере на шаге настройки базы данных ввести параметры из таблицы выше

## Требования Битрикса, которые закрывает это окружение

Расширения PHP: `mysqli`, `mbstring`, `gd`, `zip`, `xml`, `intl`, `exif`,
`sockets`, `bcmath`, `opcache`, `curl`, `iconv`, `fileinfo`, `json`, `zlib`.

Настройки PHP: `memory_limit=512M`, `max_execution_time=600`,
`max_input_vars=10000`, `upload_max_filesize=1024M`, `post_max_size=1024M`,
`mbstring.func_overload=0`, `default_charset=UTF-8`, включённый `opcache`.

Настройки MySQL: отключён строгий режим (`sql-mode=`), `innodb-strict-mode=0`,
кодировка `utf8mb4`. Без этого мастер установки Битрикса ругается на базу.

Проверить всё это после установки можно в админке:
**Настройки → Инструменты → Проверка системы**.
