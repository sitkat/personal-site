# Персональный сайт — учебный проект (1С / Bitrix)

Учебный проект: серия практических работ по вёрстке и оживлению персонального
сайта. Код пишется вручную, без сборщиков и фреймворков — только HTML, CSS,
JavaScript, jQuery и jQuery UI (подключаются с CDN).

## Структура проекта

```
index.html          Главная
about.html          О себе
services.html       Услуги
contacts.html       Контакты (форма)
sitemap.html        Карта сайта
css/style.css       Все стили
js/script.js        Весь JavaScript / jQuery
img/                Изображения
reports/ПР-N/       Отчёты по практическим работам
```

## Макет страницы

Все страницы сайта используют один и тот же блочный макет:

```
+-------------------------------------------------------+
|                    Шапка (header)                     |
+-------------------------------------------------------+
| Главная | Карта сайта | О себе | Услуги | Контакты     |  <- nav (из <ul>)
+---------+-----------------------------------+---------+
| Левая   |                                   | Правая  |
| колонка |          Контент (main)           | колонка |
| (aside) |                                   | (aside) |
+---------+-----------------------------------+---------+
|                    Подвал (footer)                    |
+-------------------------------------------------------+
```

Шапка, меню, обе колонки и подвал одинаковы на всех страницах; меняется только
содержимое `main`.

## Практические работы

### ПР 1.1 — Вёрстка сайта
Статические страницы. Каждая страница обязана содержать: `title`, заголовок,
текст, изображение, ссылку (на другую страницу этого же сайта), список, таблицу,
форму. Список навигации на следующих этапах превращается в меню средствами CSS и JS.
Кодировка файлов — UTF-8, расширение `.html`.

### ПР 1.2 — CSS
Оформление текста, форм, графики. Обязательно продемонстрировать: селекторы тега,
класса, идентификатора; контекстные, дочерние и смежные селекторы; псевдоклассы
ссылок; каскадирование; убрать подчёркивание ссылок; цветной фон заголовка; стиль
горизонтальной линии; межстрочный интервал; стиль/удаление маркеров списка; рамка
у изображения; `background-repeat`, `background-position`, `background-attachment:
fixed`; прозрачность изображения; элементы CSS3 (тени, скругления, градиенты,
переходы, анимации).

Контрольные вопросы к ПР 1.2 (на них отвечать в отчёте):
1. Что такое селектор?
2. Селектор тега, класса, ID, контекстные, дочерние, смежные селекторы.
3. Селекторы псевдоклассов для ссылок.
4. Принцип каскадирования, если к элементу применены несколько стилей.
5. Для каких элементов можно задавать фоновое изображение.
6. Когда использовать классы, а когда — идентификатор.

### ПР 2 — JavaScript, jQuery, jQuery UI
Минимум 5 методов jQuery (например `.ready()`, `.addClass()`, `.click()`,
`.find()`, `.css()`, `.filter()`, `.toggleClass()`, `.attr()`, `.prop()`,
`.trigger()`, `.hide()`, `.show()`, `.wrap()`, `.prepend()`, `.append()`,
`.html()`) и минимум 2 компонента jQuery UI — виджет и плагин.

Источники: https://html5css.ru/jquery/default.php, http://jquery.page2page.ru,
https://learn.javascript.ru/

## Правило: отчёт после каждой ПР

**После завершения любой практической работы обязательно составляется отчёт.**
Работа не считается сделанной, пока нет отчёта.

Отчёт кладётся в `reports/ПР-<номер>/otchet.md` и содержит: тему и цель, задание,
ход работы по шагам, листинги ключевого кода с пояснениями, места для скриншотов,
ответы на контрольные вопросы (если они есть в задании) и вывод.

Порядок действий по умолчанию: выполнить код → проверить, что страницы
открываются и требования задания закрыты → сразу написать отчёт → сообщить
пользователю о готовности кода и отчёта. Не ждать отдельной просьбы про отчёт.
Подробности оформления — в скилле `pr-report`.

## Скиллы

- `html-layout` — вёрстка HTML-страниц (ПР 1.1)
- `css-styling` — оформление на CSS/CSS3 (ПР 1.2)
- `js-jquery` — JavaScript, jQuery, jQuery UI (ПР 2)
- `pr-report` — составление отчёта по практической работе

## Общие правила по коду

- Язык интерфейса сайта и комментариев в коде — русский.
- Отступ — 2 пробела, кодировка UTF-8, перевод строки в конце файла.
- Никаких сборщиков, npm, препроцессоров: только чистые `.html`, `.css`, `.js`.
- Стили — в `css/style.css`, скрипты — в `js/script.js`; `style="..."` и
  `onclick="..."` в разметке не использовать.
- Правки существующего кода не должны ломать требования предыдущих ПР:
  обязательные элементы (список, таблица, форма, изображение, ссылка) остаются на
  страницах на всех этапах.
